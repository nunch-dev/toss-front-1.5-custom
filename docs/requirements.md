# 기본 기능 요구사항

이 문서는 2026-11-18에 정한 요구사항과 당시 상태를 보존한다. 아래 표의 미확인·비활성 상태를 최신 기기 상태로 해석하지 않는다. 후속 빌드·FBE·입력기·기능 검증 결과는 [기기 상태](device-status.md)와 [기본 기능 검증](basic-features.md)을 따른다.

사용자가 처음 선택한 번호: **1, 2, 3, 6, 7, 11, 18, 19, 20, 21, 22, 23, 24, 25**.
2026-11-18 추가 경량화 답변에서 접근성은 "전부 불필요", 전화·연락처·문자 앱은 "세 앱 모두 불필요"로 변경했다. 현재 유지 번호에서는 6번을 제외한다.
최신 LineageOS의 기본 범용 기능을 먼저 고르고, 그 위에 개인 기능과 보안을 추가하는 방향입니다. 선택은 기능 목표이지 동작 검증이나 기기 변경 승인이 아닙니다.

## 우선 제외 후보

추가 제외 확정(2026-11-18): TalkBack, Google 음성 서비스, AccessibilityMenu, Dialer, Contacts, messaging. 접근성·통신 공통 API와 provider는 다른 앱의 의존성이 있어 일괄 삭제하지 않는다. 키보드, WebView, 백업과 Google Play 스토어·서비스는 계속 유지한다.

미선택: 4 테마·배경 설정, 5 분할/자유형 창, 8 Jelly 브라우저, 9 계산기, 10 시계 앱, 12 Etar 달력, 13 Twelve 음악, 14 Glimpse 갤러리, 15 Recorder, 16 Aperture 카메라, 17 AudioFX, 26 Canvas 사진 편집, 27 Camelot PDF, 28 Profiles.

이는 의존성 확인 전의 후보입니다. 시계 앱 제외가 시스템 시간 기능 제거를 뜻하지 않고, 카메라 앱 제외가 다른 앱의 카메라 API 제거를 뜻하지 않습니다. 브라우저 앱 제외와 WebView 제거도 다릅니다. 기능 하나를 빼는 것이 반드시 유효한 경량화가 되거나 안전한 것은 아닙니다.

## 제거 대상으로 취급하지 않을 기반

설정, SystemUI, 패키지 설치, 권한 관리, 파일 선택/다운로드, WebView, 네트워크 스택, 미디어 기반, 보안 구성, VNDK/HAL 호환 계층은 의존성 분석 없이 삭제하지 않습니다.

## 나중에 설계할 커스텀 기능

사용자는 시스템 수준 인바운드·아웃바운드 제어에 관심이 있습니다. 기본 범용 기능을 먼저 정하기로 했으므로 방화벽 정책, 앱 구현 방식, 허용 대상은 아직 확정하지 않았습니다. 별도 추가 루팅이나 보안 기능 비활성화를 전제하지 않습니다.
